# Beyond prompting

Slidev presentation by Marco Cremaschi for three November 2026 events in Lithuania. One sequence of 115 slides follows Andrea, a fictional computer science student, from an assigned generative AI chapter to an independent explanation and a teacher’s assessment. There are no presenter notes or event-specific routes.

The deck uses Vue, Tailwind CSS and daisyUI. It retains the interactive book, particle wave, learning maps, videos, tool links and accessible reading materials. Event details are in [brief-workshop.md](brief-workshop.md).

The formal web-action slide includes selectable original interface captures and the verbatim Study response. Opening a panel is distinguished from completing its action. Dictation and desktop commands have no claimed execution; the local desktop app could not be controlled for this recording.

## Run and edit

Requires Node.js 24.12 or newer and pnpm. From the project root:

```sh
pnpm install --frozen-lockfile
pnpm generate
pnpm dev
```

Open `http://localhost:3047/`. Use the arrow keys to advance. Slidev’s native toolbar appears at the bottom left and is also reachable with Tab.

Edit the authoring sources, then regenerate:

| Location | Purpose |
| --- | --- |
| `data/opening-slides.json`, `data/workshop-slides.json` | Slide content and order |
| `data/opening-sources.json`, `data/workshop-sources.json` | Citation records |
| `data/media.json`, `data/editorial-overrides.json` | Workshop media and content refinements |
| `data/highlights.json` | Terms highlighted in the slides |
| `components/`, `utils/`, `styles/` | Typed Vue rendering, shared behavior and daisyUI theme |
| `public/images/`, `public/icons/` | Referenced presentation images and icons only |
| `assets/illustrations/` | Authoring originals and image provenance, excluded from the website |
| `booklet-genai/` | Shared textbook content, Typst source and reading edition |
| `public/materials/demo-genai/` | Canonical real-model app, runtime and verified recordings |

`data/slides.json`, `data/sources.json`, `data/flows.json`, `slides.md`, and the companion HTML/text materials are generated. Change their authoring inputs instead. `pnpm generate` is deterministic and does not recreate presenter notes.

## Validate and distribute

```sh
pnpm check                # Content, references, missing/unused images and probability maths
pnpm build                # Lightweight static website in dist/
pnpm check:browser        # Full browser checks against the running dev server
pnpm export               # Tagged PDF in exports/EduForum-2026.pdf
pnpm kit                  # Portable ZIP after building and exporting
```

Browser checks and PDF export need a compatible Playwright Chromium installation (`pnpm exec playwright install chromium`). Set `DECK_URL` to test a dev server on another port. Browser checks traverse every slide, validate image loading/layout, keyboard navigation, presenter previews, static print and the responsive reading guide. Set `CAPTURE=0` to avoid saving per-slide screenshots. New reports go to ignored `output/review/`; generated distributions go to ignored `dist/` and `exports/`.

The build omits downloaded model weights by default, avoiding a second copy of the local model. For a complete offline website that includes the prepared weights:

```sh
INCLUDE_MODEL_WEIGHTS=1 pnpm build
```

The portable ZIP always excludes weights. Its bundled server shares one prepared model between the source app and compiled deck. The archive contains editable source, the compiled deck, PDFs, runtime, recordings, licences, and a SHA-256 manifest. Packaging rejects stale material copies. It refreshes the exported textbook PDF from the canonical booklet build.

## Materials

- `public/materials/kit.html`: chapter, prompts, maps, activities, assessment and app.
- `public/materials/lettura.html`: all slides in a reflow reading guide, with text preferences.
- `public/materials/booklet-genai/Fondamenti_GenAI_Cremaschi.pdf`: the fictional textbook chapter.
- `public/materials/booklet-genai/lettura.html`: equivalent HTML chapter.
- `exports/EduForum-2026.pdf`: presentation PDF, generated by `pnpm export`.

Serve HTML over HTTP. Keep `exports/` and `public/` together when sharing the PDF: its local material links are relative. Rebuild the booklet separately with `pnpm booklet:build` after editing `booklet-genai/contenuti.mjs`; see [booklet-genai/README.md](booklet-genai/README.md) for Typst requirements and verification limits.

## Real model exercise

The canonical app is `public/materials/demo-genai/`; `demo-genai/tests/` contains its maths, UI and recording checks. The app uses actual quantised Qwen2.5-0.5B-Instruct inference through bundled Transformers.js and ONNX Runtime. The model preparation script pins a public revision and checks sizes and SHA-256 hashes:

```sh
node public/materials/demo-genai/prepare-model.mjs
node public/materials/demo-genai/serve.mjs
```

Open `http://127.0.0.1:4176/`. The approximately 786 MB model stays in one ignored local directory. After preparation, CPU/WASM inference works offline; WebGPU is optional. The English recording, captions, transcript and measured results remain usable without loading the model. See the app’s [README](public/materials/demo-genai/README.md).

The distributed application was implemented with Codex. The Claude slide provides a reproducible assignment prompt; it does not claim a fabricated Claude execution. Maps, student responses and classroom assessments are constructed teaching examples unless explicitly identified as real recorded executions. Tool conditions can change; product documentation and educational evidence remain distinct in the source index.

The Agent Skills section adds 12 publisher-documented skills across document work, research and interactive teaching. `data/skills-research.json` records requirements, licensing, proposed book-related prompts and dated discovery signals. These skills were source-reviewed, not installed or executed for the survey. The generated `public/materials/skills-guide.html` includes installation routes and version-pinned benchmark references. Prompt blocks use daisyUI `mockup-code` in both the deck and reading materials.
