Stage 1: Core Concepts & Flow

Distinguishing training, inference, context, and retrieval mechanisms.

Estimated: 4 Minutes

1. Training / Fine-tuning

Updates the internal model parameters (weights). Optimization compares predicted probabilities with training examples to reduce error, creating a changed version of the model.

2. Ordinary Inference

Calculates output distributions using fixed parameters. Changing the prompt context alters available input data for that step, but does not update internal weights.

3. Document Retrieval (RAG)

Fetches external passages dynamically and inserts them into the prompt context window. The model parameters remain strictly fixed while retrieved content is read.

Table 1: Key Interventions & What Changes

Intervention What Changes Model Parameters State

Document retrieval (RAG) External passages supplied as context. FIXED

Expected Answer & Conceptual Breakdown

No, it does not prove parameter updates. Ordinary inference runs calculations using parameters that are already available (fixed weights). Making information or definitions available in the prompt changes only the information available to the current inference pass. It does not update or retrain the model's internal weights.
