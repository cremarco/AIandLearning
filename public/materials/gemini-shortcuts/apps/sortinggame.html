Evidence & Theoretical Foundation

Exact citations and explanations from Chapter 01 ("Foundations of Generative Artificial Intelligence" by Marco Cremaschi).

Item 1: Parameter Updates Section 1.2, Page 5
"Parameters are numerical values used in the model's transformations... While pretraining, the system compares its predicted distribution with the tokens actually present in examples, then changes the parameters to reduce an aggregate error."

Takeaway: Any intervention that alters model weights is part of training or fine-tuning.

Item 2: Fixed-Model Calculations Section 1.2 & Glossary, Page 5 & 18
"Ordinary inference runs calculations with parameters that are already available. Keeping the model fixed while changing the input studies the effect of context."

Takeaway: Standard generation uses fixed parameters to compute next-token output distributions without modifying weights.

Item 3: Adding Prompt Context Section 1.2, Table 1 & Study Resource B
"A new message in the context... changes information available to the current inference... Does uploading the chapter automatically update model weights? No. Making material available to context or retrieval does not itself update parameters."

Takeaway: Prompt engineering, system instructions, and RAG affect context for inference, not model parameters.
