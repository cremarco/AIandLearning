Comparing Training, Ordinary Inference, and RAG (Cremaschi, 2026)
Parameter Updates (Training) Modifies internal numerical weights ($z$). Changes the model itself permanently (Sec 1.2).
Context Changes (Inference & RAG) Modifies available text tokens for current step. Model parameters remain strictly fixed (Sec 1.2, 1.7).
