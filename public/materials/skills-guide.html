What is a skill?

An Agent Skill is a folder with a SKILL.md file containing metadata and workflow instructions, plus optional references, scripts and assets. A product command invokes a feature; an informal shortcut labels a request. Skills require a host that can discover them and supply the necessary tools.

Agent Skills specification · OpenAI skill and plugin concepts

Installation depends on the host

In the recorded account, ChatGPT web offered Plugins → Skills → Add skill → Upload from computer. The four reviewed packages were uploaded and selected in Work mode. Availability depends on the account and workspace. The terminal commands below are for compatible coding agents; they are not ChatGPT slash commands.

For coding agents, review the publisher’s files, dependencies and license before installing. The Skills CLI asks which skills and agents to install for; installation is project-scoped by default. Installing the instructions does not install their Python, Node or external service dependencies. A portable format does not guarantee identical behaviour across hosts.

The old openai/skills repository is deprecated; use current OpenAI plugin documentation and openai/plugins examples.

Evidence of effectiveness

SkillsBench v4 evaluates 87 tasks across 8 domains under matched conditions for 18 model–harness configurations. Average pass rate rises from 33.9% to 50.5%, an increase of 16.6 percentage points. Focused bundles performed better than larger, exhaustive ones. Li et al. · SkillsBench v4.

SWE-Skills-Bench v2 evaluates 98 software-engineering skills across four agent–model configurations. It finds no statistically significant effect for 92 skills; the average pass ratio changes from 76.6% to 76.9% (+0.3 percentage points). Han et al. · SWE-Skills-Bench v2.

The four demonstrations test outputs and controls on one chapter with one model and account. They do not establish learning gains or compare skill efficacy. Benchmark aggregates do not rank these packages or measure student learning. Both are preprints. Older search snippets report earlier versions with different task counts and results; the figures above are pinned to the linked versions.

A separate analysis of 307 selected failure cases describes how excessive procedure and templates can cause errors or wasted effort. This is a failure taxonomy, not a population-wide failure rate. Dong et al. · Agent Skills Can Be Harmful.

How to choose

The following is a practical inference from the sources, not a measured ranking of these packages: prefer a narrow recurring task with a clear input, output and check. For one representative task, compare factual errors, missing requirements, file usability and effort with and without the skill. For teaching, also assess what the learner can explain without assistance.

Research method

  1. Start from the skills.sh directory and authoritative vendor repositories.
  2. Read the actual skill or publisher documentation; identify runtime, tools, licensing and limits.
  3. Use install counts and repository stars only as dated discovery signals, not evidence of efficacy.
  4. Read the latest arXiv versions rather than relying on older search snippets.
  5. Distinguish proposed classroom uses from measured agent benchmarks and recorded ChatGPT outputs.
  6. Import four version-pinned publisher packages through the ChatGPT web Skill library, attach the original workshop chapter, inspect the results and record real browser actions. Keep unexecuted catalogue examples labelled separately.
