The key distinction
Training changes the model's parameters. Ordinary inference uses existing parameters to produce an output from the current input and context.

What is updated when the system learns from prediction errors during pretraining?

§1.2, p. 5
Hide answer

Expected explanation

The model's numerical parameters are updated through optimisation to reduce aggregate prediction error.

3

How can a different prompt change the output if the model's parameters remain fixed?

§1.2, pp. 5–6
Hide answer

Expected explanation

Ordinary inference uses the current input and context with fixed parameters. Changing the context can therefore change the output distribution without retraining.

Final takeaway: Changing context changes the information available to inference; changing parameters requires training or fine-tuning. A different answer alone is not evidence that the model has learned new weights.
