Experiment 1 — Training

Andrea trains a new version of his model using examples and prediction error. During optimisation, numerical parameters are updated.

§1.2, pp. 5–6
Explanation revealed

Expected explanation

Training changes the model's parameters through optimisation. During ordinary inference, the model performs calculations using already available parameters. Training a new version therefore changes the model itself; changing only the input does not.
