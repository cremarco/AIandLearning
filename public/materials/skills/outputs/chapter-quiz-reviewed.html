1. Training

What does optimisation update during training?

Reveal model answer and criteria

Model parameters (weights). Optimisation changes numerical parameters to reduce aggregate prediction error.

Check: Name the parameters and connect their update to prediction error. (§1.2)

2. Context and inference

True or false: correctly using a definition in your prompt proves that the model was trained on that message. Explain.

Reveal model answer and criteria

False. A definition can influence the answer through context while ordinary inference uses fixed parameters.

Check: Distinguish context available during inference from parameter updates during training. (§1.2)

3. Retrieval-augmented generation

Explain RAG and name one reason its answer may be wrong.

Reveal model answer and criteria

During use, retrieval supplies passages as context to a model. Retrieval itself does not update model weights. It may select irrelevant material, and the response may misinterpret a passage.

Check: Identify retrieved context, fixed parameters during ordinary inference, and one failure mode. Accept equivalent explanations. (§§1.2, 1.7)
