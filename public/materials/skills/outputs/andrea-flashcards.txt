How do training and ordinary inference differ in their use of model parameters? | Training updates parameters through optimisation to reduce prediction error. Ordinary inference calculates outputs using fixed, already available parameters. (§1.2)
When Andrea adds a new definition to a prompt, what changes, and what does using that definition demonstrate about model weights? | The definition changes the context available to current inference. Using it does not demonstrate that model weights have changed. (§1.2)
How does retrieval-augmented generation (RAG) supply new information without a parameter update? | RAG retrieves selected document passages and supplies them as generation context. The consulted collection and model parameters are distinct components, so weights can remain unchanged. (§1.7)
