Cheatsheet

Process What changes or happens? Parameters
Training / fine-tuning Optimisation updates numerical model parameters. Pretraining uses examples and prediction error. Updated (§1.2)
Ordinary inference Calculations use the available parameters and current input/context. Changing the prompt changes available information. Fixed (§1.2)
RAG A retrieval component selects document passages and supplies them as context for generation. Retrieval itself does not update weights (§§1.2, 1.7)

Example: Adding “In this chapter, X means Y” can influence an answer through context. Using that definition does not establish that training occurred. (§1.2)

Watch for: A newer document can supply newer information without changing weights. Retrieval may fail, choose irrelevant passages or provide material the response misinterprets. Check what the cited passage actually supports. (§1.7)
