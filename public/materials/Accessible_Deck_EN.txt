SLIDE S52SDL — What is self-directed learning?
Page 11 / 115
Self-directed learning is a process in which learners take the initiative to identify learning needs, set goals, choose resources and strategies, and evaluate outcomes.
1. Identify a goal
What do I need to learn, and what do I want to achieve?
2. Choose a path
Which resources, people and strategies will help me learn?
3. Evaluate progress
What have I learned, and what should I change? Self-assessment helps here.
Andrea’s example: “I need to distinguish training from inference. I will use the chapter and a concept map, then check whether I can explain the difference.”
Teachers and peers can support the process; the learner takes responsibility for the choices.
[EDU_SELF_DIRECTED] National Library of Medicine. (n.d.). Self-Directed Learning as Topic (MeSH D000073819). Definition attributed to Knowles (1975), Self-directed learning: A guide for learners and teachers. New York: Association Press.
https://www.ncbi.nlm.nih.gov/mesh/2023167
Conceptual definition, not an efficacy trial. Knowles’s definition was verified through the NLM entry; the full original book was not consulted. The three groups and Andrea’s example are workshop illustrations.

SLIDE S52SA — What is self-assessment?
Page 12 / 115
Self-assessment means judging your own work and learning against explicit criteria, then using that judgment to improve.
1. Check the criteria
What should I be able to explain or do?
2. Look for evidence
What can I demonstrate? Where do I still struggle?
3. Choose a next step
What will I revise, practise or check again?
Andrea’s example: “I can explain what a token is, but I still confuse training and inference. I will revise that link in my map and explain it again.”
AI can offer feedback; the learner checks the evidence and decides what to improve.
[EDU_SELF_ASSESSMENT] Andrade, H. L. (2019). A critical review of research on student self-assessment. Frontiers in Education, 4, 87.
https://doi.org/10.3389/feduc.2019.00087
Definition and review of 76 empirical studies; not validation of this workshop, its three-step illustration or AI feedback. Andrea’s example is a constructed teaching scenario.

SLIDE S53EX1 — /eli5 · Causal attention in plain language
Page 27 / 115
Book §5 · The Transformer decoder
Prompt · informal shortcut: /eli5 Using only §5 of the attached book, explain causal attention to a 15-year-old in no more than 80 words. Explain which tokens a position can use, why future tokens are blocked and what happens after a token is generated. Keep the technical meaning. Answer in English.
Actual ChatGPT response: Causal attention is a mechanism that helps a Transformer language model predict the next token (a piece of text).
Each position can use information from earlier tokens and itself, but not from later positions. A causal mask blocks future tokens so the model cannot use information that should not yet be available.
Once a new token is generated, it is added to the sequence. The model can then use it to predict the next token, repeating the process.
Use it to simplify an explanation while preserving the causal constraint.

SLIDE S53EX2 — /mindmap · How a model generates text
Page 28 / 115
Book §§2–7 · A text map with named relationships
Prompt · informal shortcut: /mindmap Using only §§2–7 of the attached book, create a text mind map centred on “Text generation”. Use five branches and label each relationship. Include tokens, decoder blocks, probabilities, generation and training. Distinguish parameter updates from ordinary inference. Answer in English. Keep the complete response within 100 words.
Actual ChatGPT response: TEXT GENERATION
Text generation
1. Tokens — are converted into numerical IDs, then embeddings with positional information.
2. Decoder blocks — transform representations using causal attention, allowing access only to current and earlier positions.
3. Probabilities — are calculated from logits through softmax; temperature changes their concentration.
4. Generation — selects and appends one token, then repeats inference until stopping.

SLIDE S79F — Read the formula from the chapter
Page 70 / 115
Softmax with temperature · identify the role of each symbol
1. zᵢ · score
A number calculated by the model for candidate token i.
2. T · temperature
A positive setting that rescales scores before conversion.
3. pᵢ · probability
The exponentiated score divided by the sum over all candidates.
p_i = exp(z_i/T) / sum_j exp(z_j/T), T > 0. Read: exponentiate each score divided by temperature, then divide by the sum over all candidates.
The denominator makes the probabilities sum to one. Probability is not truth.
